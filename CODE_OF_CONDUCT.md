# Code of Conduct / 社区行为准则

## Our Standard

AgentFlowing welcomes contributors regardless of experience, identity, background, nationality, language, or ability. We expect communication to remain respectful, technically honest, and focused on improving the project.

Positive behavior includes:

- giving specific, constructive feedback;
- assuming good intent while still discussing evidence;
- acknowledging tradeoffs and correcting mistakes;
- respecting privacy and responsible disclosure;
- making space for newcomers and different perspectives.

Unacceptable behavior includes harassment, discrimination, threats, sexualized content, personal attacks, deliberate disruption, doxxing, or publishing another person's private information.

## Enforcement

Maintainers may edit or remove comments, commits, issues, pull requests, or other contributions that violate this standard. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

Report conduct concerns privately to a maintainer using a contact method listed on the repository owner's GitHub profile. Do not use public issues for reports that contain private or sensitive information.

## 中文说明

AgentFlowing 欢迎不同经验、身份、背景、国籍、语言和能力的贡献者。交流应保持尊重、诚实并聚焦项目改进。

我们鼓励具体且建设性的反馈、基于证据的讨论、主动纠正错误、保护隐私以及帮助新贡献者。骚扰、歧视、威胁、色情内容、人身攻击、恶意干扰、开盒或公开他人隐私均不可接受。

维护者可以编辑或删除违反准则的评论、Commit、Issue、Pull Request 或其他内容；严重或重复违规可能导致暂时或永久禁止参与。涉及隐私的信息请通过仓库所有者 GitHub 资料中的私密联系方式报告，不要发布到公开 Issue。
